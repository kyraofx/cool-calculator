# Simple Calculator

A lightweight, dependency-free calculator built with HTML, CSS, and JavaScript.

## Live Demo

[Try the calculator](https://kyraofx.github.io/simple-calculator/)

## Features

Mouse and touch input, keyboard support, basic arithmetic operations, Enter to calculate, Escape to clear, Backspace to delete.

## Built With

HTML, CSS, JavaScript

## Run Locally

Clone the repository and open `index.html` in your browser.
